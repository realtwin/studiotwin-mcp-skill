# studiotwin-mcp-skill

An [AgentSkill](https://modelcontextprotocol.io) for driving **StudioTwin's**
generative 3D / asset pipeline through its MCP server — text → motion, image → 3D,
image → environment, and texture → material — for Unreal Engine and
virtual-production workflows.

> **Status: v1 draft.** The skill contract in [`SKILL.md`](./SKILL.md) is
> scaffolded; sections marked `[TODO]` await the StudioTwin MCP server spec
> (tool names, auth, endpoints).
